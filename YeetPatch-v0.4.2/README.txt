YeetPatch is an official launcher/updater for the game "Voices of the Void".
It is used to download and install the game itself, as well as to update it to the latest version.

Features:
- Ability to check your game for available updates and install them if desired;
- Ability to download and install any version of the game that was ever released;
- Automatic backup of SaveGames and Config folders before updating/installing a version;
- Simple Render API switcher (Vulkan/DirectX 11/DirectX 12);
- Launch arguments box to pass custom arguments to the game on launch;
- Automatic updates for the launcher (opt-out available);
- Online notice check for any important announcements, votv/yeetpatch related (opt-out available);
- System specs export button to aid with bug reports;
- Community Discord and VOTV bugs/feedback buttons for easy access;

Usage:
- Extract the contents of the archive to a folder of your choice;
- Run YeetPatch.exe;
- Set the path to your VOTV installation (VotV.exe) or set a path to install the game to if you don't have it yet;
- Use the "Check / Update" button in the UPDATE tab to check for updates and install them if available;
- Use the "Export Specs" button in the UPDATE tab to print your computer specs in order to aid in bug reporting;
- Use the "Select Version" button in the INSTALL tab to select a version to download, then "Install / Change" to install it;
- Use the "Cache" button in the INSTALL tab to set a path to the optional download cache (and enable it), which helps you save bandwidth if you switch between versions often or have to download a newer version;
- Use the SETTINGS/INFO tab to opt-in/out of Online Updates for YeetPatch and Online Notices, change the render API the game launches with and additionally, add custom launch arguments via the box provided.
- The SETTINGS/INFO tab also contains useful links to our report/feedback forms, as well as our discord;

Commandline usage:
Adding --autolaunch to the command line will automatically update/check and launch the game, bypassing the auto launch checkbox in the GUI. It will cancel on declined update (if available);
